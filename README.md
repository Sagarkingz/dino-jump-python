# 🦖 Dino Space Jump (Python Edition)

A retro offline runner game built with Python and Pygame featuring procedural 2D pixel art, dynamic obstacles, and palette shifts every 1000 points.

---

## ⚡ Quick Download (Windows - No Python Needed)
👉 **[Download DinoJump-Windows.zip](https://github.com/Sagarkingz/dino-jump-python/releases/download/v1.0.0/DinoJump-Windows.zip)**

1. Download and extract **`DinoJump-Windows.zip`**.
2. Open the extracted folder and double-click **`DinoJump.exe`** to play.

---

## 🎮 How to Run from Source Code (For Developers)

```bash
# 1. Clone this repository
git clone [https://github.com/Sagarkingz/dino-jump-python.git](https://github.com/Sagarkingz/dino-jump-python.git)

# 2. Enter folder
cd dino-jump-python

# 3. Install requirements
pip install -r requirements.txt

# 4. Start game
python main.py
